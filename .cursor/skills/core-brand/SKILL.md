### How to Use the Template Programmatically

When generating presentations with python-pptx:

1. The `.potx` file must be converted for python-pptx by patching `[Content_Types].xml` — replace `presentationml.template.main+xml` with `presentationml.presentation.main+xml`
2. Reference layouts by name (e.g., `'Title and Content'`, `'Cover 1'`)
3. Access placeholders by `placeholder_format.idx` (0 = title, 1 = content/subtitle, 10+ = additional placeholders)
4. Save output as `.pptx`

```python
from pptx import Presentation
import zipfile

# Convert .potx to .pptx for python-pptx compatibility
with zipfile.ZipFile('template.potx', 'r') as zin:
    with zipfile.ZipFile('template.pptx', 'w') as zout:
        for item in zin.namelist():
            data = zin.read(item)
            if item == '[Content_Types].xml':
                data = data.replace(
                    b'presentationml.template.main+xml',
                    b'presentationml.presentation.main+xml'
                )
            zout.writestr(item, data)

prs = Presentation('template.pptx')
layout = prs.slide_layouts[4]  # 'Title and Content'
slide = prs.slides.add_slide(layout)
slide.placeholders[0].text = "My Title"
slide.placeholders[1].text = "My content here"
prs.save('output.pptx')
```

## Features

### Smart Color Application

- Apply Frontiers Blue (`#003BDE`) as the primary accent color for headings, links, and CTAs
- Use Cyan (`#00A0DC`) for secondary interactive elements
- Use Teal (`#279F94`) for success indicators and open access badges
- Use the neutral palette for text hierarchy (Near Black for primary text, Dark Gray for secondary)
- Maintain high contrast ratios for accessibility (WCAG AA minimum)

### Text Styling

- Headings: Museo Sans 500 (or Calibri Bold fallback), Frontiers Blue or Near Black depending on context
- Body text: Museo Sans 300 (or Calibri Regular fallback), Dark Gray (#545454) on light backgrounds
- Links: Frontiers Blue (#003BDE), with Dark Blue (#001991) on hover
- Use adequate line-height (1.5 for body text, 1.2 for headings) for readability

### Shape and Accent Colors

- Use accent colors from the official theme palette for data visualizations and diagrams
- Cycle through: Teal (#279F94), Green (#91CF7A), Purple (#856DF0), Red (#E7323B), Orange (#FF953E), Cyan Bright (#31C7D1)
- Maintain visual consistency while ensuring sufficient contrast between adjacent elements

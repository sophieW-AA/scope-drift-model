# Journal Launch — Checklist Orchestrator

## Overview

This skill manages the end-to-end launch of a new Frontiers journal. It coordinates across systems and teams to ensure every step is completed on time.

## When to Use

- A new journal has been approved and needs to be launched
- Need to generate or review a launch checklist
- Need to track progress across launch workstreams
- Need to draft launch communications (announcements, social media, emails)

## Prerequisites

- `core-salesforce` — create journal objects, configure APC
- `core-confluence` — publish journal profile page, scope statement
- `core-jira` — create launch project with task breakdown
- `core-brand` — generate visual assets (logo lockup, social cards)
- `core-email` — draft launch announcement emails

## Workflow

1. **Intake** — Collect journal metadata: title, field, chief editor, APC, scope, target launch date
2. **Generate checklist** — Produce a phased checklist (T-8w to launch day)
3. **System setup** — Guide Salesforce configuration, editorial platform setup
4. **Content creation** — Draft scope statement, aims & scope page, About section
5. **Marketing assets** — Generate social media cards, email templates, press release
6. **Communications plan** — Schedule announcements, coordinate with editorial board
7. **Go-live verification** — Final checks across all systems before launch

## Output Format

- Phased launch checklist (Jira-ready)
- Scope statement draft
- Marketing asset briefs
- Communication timeline
- Go-live readiness report

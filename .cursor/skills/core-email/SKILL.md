# Email Drafting

## Overview

This skill generates professional, on-brand email drafts for common Frontiers communication needs.

## When to Use

- Drafting editorial board invitation emails
- Writing author outreach or submission solicitation emails
- Creating reviewer request templates
- Drafting journal launch announcements
- Any professional correspondence representing Frontiers

## Email Types

### Board Invitation
- Personalized reference to the candidate's research
- Clear role description and time commitment
- Journal scope and vision
- CTA with accept/decline link

### Author Outreach
- Reference to specific recent publications
- Connection to journal scope
- Clear submission invitation
- Mention of relevant Research Topics (if applicable)

### Reviewer Request
- Article title and abstract summary
- Timeline expectations
- Decline option with alternative reviewer suggestion

### Launch Announcement
- Journal name, scope, and vision
- Chief editor introduction
- Call for submissions
- Key dates and links

## Guidelines

- Use Frontiers professional tone: warm, clear, respectful
- Always personalize when recipient data is available
- Keep emails concise — aim for 150–250 words for outreach
- Include clear call-to-action
- Never fabricate recipient details — ask if not provided

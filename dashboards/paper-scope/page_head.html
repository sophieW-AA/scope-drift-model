Frontiers journals: how their topics are changing

209 journals · 282,689 Frontiers papers, 2023–2026

How to read this
All journals view
Each bubble is a journal. Size = number of papers. Colour = the broad field most of its papers belong to. Position = journals that publish on similar topics sit close together (the layout is an estimate, so distance is a rough guide only).
One journal
Each bubble is a topic the journal publishes in. Size = the journal's papers in that topic (in the chosen year, if you pick one). Position = topics whose papers cite each other sit closer together.
Colour: Core status
Core: inside the journal's core fields. Borderline: reviewed and judged close to the core. Outside the core. The share outside the core is the headline figure for each journal.
Colour: Broad field
Each topic is coloured by the broad field it belongs to.
Years
Use the year slider to see one year at a time. Years marked ⚠ have far fewer papers than the journal's busiest year, so changes look bigger than they are. The run is dated August 2026, so 2026 is a part year.
Tabs
Frontiers view shows every journal. Click one to open it in the Journal tab. Scope details is joined to the Journal tab by a dotted outline: it is the full report for the same journal, and changes whenever the journal does. Data & queries lists every BigQuery query behind the page.

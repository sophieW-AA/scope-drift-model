This page is a plain-language status update for the Scope Drift work (owner: Sophie Wilson). Last updated: 31 July 2026.

What this project is about

Journals can slowly change what they publish — sometimes in useful, interdisciplinary ways, and sometimes by drifting into topics that sit outside their intended focus. Scope Drift helps us see that movement early, using the citation network (which papers cite which) rather than reading every article by hand.

In short, we ask:

  • Is a journal still publishing mainly in its core subject areas?
  • How much content looks out of scope today, and is that share rising?
  • Which topic communities are driving the change?

Where we are now

The current analysis covers eight Frontiers journals over 2020–2026 (latest model run: July 2026):

  • Frontiers in Neurorobotics
  • Frontiers in Earth Science
  • Frontiers in Surgery
  • Frontiers in Aging Neuroscience
  • Frontiers in Environmental Science
  • Frontiers in Chemistry
  • Frontiers in Materials
  • Frontiers in Robotics and AI

For each journal we now have:

  • An estimate of how much content sits outside the journal’s core topic mix
  • A view of how that mix has shifted since 2020
  • Example in-scope and out-of-scope papers (preferring recent, clearly off-topic examples where possible)
  • Community descriptions with keywords, so readers can understand what each topic cluster is about

We also produce a short Journal Scope Drift Report (PDF) and an interactive combined dashboard with scope, drift, network maps, and paper examples in one place.

How the topic labels work (Toby’s taxonomy)

The citation network groups papers into topic communities. To give those communities readable names and descriptions, this project uses Toby’s taxonomy work — mapping clusters onto the Frontiers / Advanced Analytics taxonomy so labels, summaries, and keywords stay consistent with the wider D&A language.

How we decide “in scope” vs “out of scope”

At a high level:

  1. Find each journal’s core topic communities (the set that covers most of its papers).
  2. Review nearby communities that might be borderline (adjacent / interdisciplinary, but not core).
  3. Flag clearly wrong papers with simple title rules (for example, fintech papers in an environmental journal, or civil-construction titles in earth science).
  4. For a smaller set of suspicious titles sitting inside broad core communities, run an editorial-style check and demote the ones that do not fit.

This is still a signal for investigation, not a final editorial audit. Citation-based methods can over-flag methods papers and reviews that cite widely.

Validation so far

We compared the model against a manual ground-truth pack for five of the journals. After the latest scope-check improvements, agreement rose to about 76% (from roughly mid-50%s earlier), with fewer cases where the model said “in scope” but reviewers said “out of scope”. Aging Neuroscience remains the hardest journal in that pack and is a focus for further tuning.
